# Boneco do Abismo — página informativa

O site publicado em GitHub Pages é apenas explicativo. Ele informa que o projeto é destinado a computadores Windows e Linux.

- Não haverá versão para iPhone ou Android.
- O site não instala nem executa o programa.
- O programa, o servidor, a IA, o áudio e a transmissão são executados/configurados no computador.
- A voz usa como referência `assets/BONECO_MAPA_2D/voz/VOZ_RAPIDA_MASCULINA.wav` com Coqui XTTS, desde que o modelo e as dependências estejam instalados.

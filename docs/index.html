Boneco do Abismo

Windows e Linux somente

O Boneco é para computador.

Este site é somente explicativo. O projeto Boneco do Abismo é destinado a computadores com Windows ou Linux, onde ficam o servidor, os recursos de inteligência artificial, o processamento de voz e as ferramentas de transmissão. As instruções do projeto não incluem instalação em celular.

Sobre a voz original

O projeto contém o arquivo de referência vocal assets/BONECO_MAPA_2D/voz/VOZ_RAPIDA_MASCULINA.wav e o serviço de síntese está preparado para usar o Coqui XTTS com essa referência. A geração de falas também depende da instalação e configuração do modelo e das dependências necessárias.

Importante: não haverá versão para celular, iPhone ou Android. Esta página não instala nem executa o Boneco e não oferece instalação móvel; ela serve apenas para explicar o projeto. O código e as instruções para computador ficam no repositório GitHub.

Instalação no Windows

Extraia o ZIP, instale Python 3.12 e execute o iniciador incluído na pasta do projeto.

Set-ExecutionPolicy -Scope Process Bypass
.\start_boneco_windows.ps1

O iniciador cria o ambiente virtual e instala as dependências básicas. Mantenha o terminal aberto enquanto estiver usando o servidor.

Instalação no Linux

Instale Python 3.12, venv e pip pelo gerenciador da sua distribuição. Depois, na pasta extraída do projeto, execute:

python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m pip install -e . --no-deps
BONECO_GAME_DIR="$PWD" BONECO_GAME_ASSETS_DIR="$PWD/assets" BONECO_GAME_HOST=127.0.0.1 BONECO_GAME_PORT=9292 python -m uvicorn boneco_game.main:app --host 127.0.0.1 --port 9292

Abra http://127.0.0.1:9292 no navegador do próprio computador.

Os recursos completos de live podem precisar de dependências adicionais, modelos de IA, credenciais privadas e configuração de áudio/transmissão. O ZIP é o código do projeto, não um instalador .exe ou pacote AppImage pronto.

Voz do Boneco original

O projeto já contém a referência de voz assets/BONECO_MAPA_2D/voz/VOZ_RAPIDA_MASCULINA.wav. O serviço de síntese aponta para esse arquivo como voz de referência do XTTS, para aproximar as falas geradas da voz do Boneco. Para gerar voz, o ambiente precisa ter as dependências/modelo XTTS instalados e configurados.

Não substituí a voz por uma voz aleatória do navegador. A voz original depende do arquivo WAV de referência e do mecanismo XTTS do projeto; não posso afirmar que a síntese foi testada nesta máquina.
